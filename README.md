# MatStruct Lab

یک وب‌اپلیکیشن تعاملی، فارسی و راست‌چین برای یادگیری MATLAB در مهندسی عمران، گرایش سازه؛ از مبانی ماتریس‌ها تا تحلیل دینامیکی و المان محدود.

## امکانات

- مسیر یادگیری ۸ مرحله‌ای از پایه تا حرفه‌ای
- درس‌های تخصصی روش سختی مستقیم، دینامیک سازه و FEM
- آزمایشگاه تعاملی کدنویسی با نمونه ماتریس سختی تیر
- نمایش خروجی عددی و نمودار تغییرشکل عضو
- ثبت پیشرفت دوره در مرورگر کاربر
- پروژه‌های عملی خرپا، تحلیل طیفی و قاب سه‌بعدی
- رابط کاملاً فارسی، RTL، واکنش‌گرا و مناسب موبایل

## اجرای محلی

پیش‌نیاز: Node.js نسخه `22.13.0` یا جدیدتر.

```bash
npm install
npm run dev
```

سپس آدرس نمایش‌داده‌شده در ترمینال را در مرورگر باز کنید.

## ساخت نسخه نهایی

```bash
npm run build
```

## فناوری‌ها

- React 19
- TypeScript
- vinext / Vite
- Tailwind CSS 4
- Cloudflare Workers compatible output

## وضعیت پروژه

این نسخه یک نمونه حرفه‌ای و قابل توسعه است. اجرای کد MATLAB در محیط آزمایشگاه به‌صورت شبیه‌سازی‌شده انجام می‌شود و می‌توان در نسخه بعدی آن را به MATLAB Online یا یک سرویس محاسباتی متصل کرد.
